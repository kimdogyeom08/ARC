# league of legends에서 챔피언, 룬을 랜덤으로 뽑아주는 앱(사이트)

## 1. 프로젝트 개요

### 1.1 프로젝트 명
ARC(All Random Challenge)

### 1.2 프로젝트 목적
리그 오브 레전드에서 매번 새로운 것을 해보고 싶으나 고민하기 어려울때 쓰는 간단한 룰렛 풀스택 웹 앱

### 1.3 개발 범위
- 메인 화면(룰렛 화면에서 만든 결과물을 메인화면에서 간단하게 보여주기, 결과물을 눌렀을때 자세하게 보여주기)
- 룰렛 화면(캐릭터(챔피언)와 캐릭터 설정(룬)이 돌아가는 기능, 최종 창에 하나가 완료 될때마다 그 하나를 최종 창에 넣기)
- 데이터들을 메인 화면에서 저장/조회/삭제할 수 있는 기능

## 2. 기술 스택
- 프런트엔드: HTML, CSS, 리액트, 자바스크립트
- 백엔드: Node.js, Express
- 데이터베이스: PostgreSQL

## 3. 기본 사항
- 프런트엔드와 백엔드를 따로 개발
- 메인 화면에서 저장된 데이터들을 보여주고 한번 클릭하면 커지며 자세한 내용을 보여주고 다운로드도 받을 수 있게 함
- 이미지 파일로 다운로드 받을 수 있게함
- 새로운 캐릭터나 설정들이 들어올 경우, 자동으로 넣어주는 기능(API 받기)

# 메인 화면 PRD

## 1. 목적
룰렛에서 저장한 챔피언·룬 빌드를 한눈에 비교하고, 선택한 빌드의 스킬 순서와 아이템 빌드까지 확인·관리하는 화면이다.

## 2. 사용자 흐름
1. 사용자가 메인 화면에 진입하면 상단 헤더와 저장된 빌드 목록을 확인한다.
2. 가장 최근에 저장된 빌드가 기본 선택되어 상단 상세 패널에 표시된다.
3. 목록의 다른 빌드를 선택하면 선택 항목이 바뀌고, 상단 상세 패널이 해당 빌드의 정보로 갱신된다.
4. 선택 빌드의 이미지 다운로드 또는 삭제를 실행하거나, 우측 하단의 추가(+) 버튼을 눌러 룰렛 화면으로 이동한다.

## 3. 기능 요구사항
- **상단 헤더:** 왼쪽에 다크 모드 전환 버튼, 가운데에 앱 로고와 `All Random Challenge` 앱 이름을 표시한다. 다크 모드 전환 시 화면 전체의 색상 테마를 변경한다.
- **선택 빌드 상세 패널:** 저장 목록 위에 넓은 패널을 두어 현재 선택된 빌드를 표시한다. 빌드가 있을 때 기본 선택은 가장 최근 저장 항목으로 한다.
  - 챔피언 이미지와 이름을 표시한다.
  - 룬은 주 룬 경로, 선택 룬, 보조 룬 경로와 선택 룬, 룬 파편을 경로와 선택 순서가 구분되도록 배치한다.
  - 추천 스킬 마스터리 영역은 데이터가 없을 때 비워 둔다. 스킬 추천 데이터가 제공되는 경우에만 스킬 아이콘을 순서대로 표시한다. 이 영역의 오른쪽 위에는 작은 이미지 다운로드 아이콘 버튼을 배치한다. 버튼은 현재 선택된 빌드 전체를 PNG 이미지로 다운로드하며, 툴팁 또는 접근 가능한 이름으로 동작을 안내한다.
  - 추천 아이템 빌드 영역은 데이터가 없을 때 비워 둔다. 아이템 추천 데이터가 제공되는 경우에만 아이콘을 구매 순서대로 표시한다.
  - 추천 라인은 텍스트 대신 해당 라인을 나타내는 아이콘 이미지로 표시한다. 라인 아이콘은 프로젝트에 포함한 자체 제작 이미지 또는 사용 허가가 확인된 이미지 자산을 사용하며, OP.GG 페이지에서 자동 수집하지 않는다. 접근성을 위해 아이콘에는 라인 이름을 대체 텍스트로 제공한다.
  - 선택 빌드 삭제 동작을 제공한다. 삭제 전 확인을 받고, 취소하면 데이터가 유지된다. 이미지 다운로드는 추천 스킬 마스터리 영역 오른쪽 위의 작은 버튼으로 제공한다.
- **저장 빌드 목록:** 상세 패널 아래에 빌드를 한 행씩 요약해 표시한다. 최신 저장순으로 정렬하고, 각 행은 챔피언, 룬 구성, 스킬 순서(데이터가 있을 때만), 라인 아이콘을 보여준다. 목록에는 선택한 행이 명확히 표시되어야 한다. 아이템 빌드 전체는 상세 패널에서 확인하며, 데이터가 없으면 해당 영역을 비워 둔다.
- 목록 행을 선택하면 전체 페이지를 벗어나지 않고 상단 상세 패널이 해당 행의 빌드로 갱신된다. 목록 행과 선택 상세 패널은 같은 저장 항목을 가리켜야 한다.
- **빌드 추가:** 화면 우측 하단의 `+` 버튼은 새 룰렛 결과를 만들 수 있도록 룰렛 화면으로 이동시킨다.
- **빈 상태:** 저장 빌드가 없으면 상세 패널과 목록 대신 저장된 빌드가 없다는 안내 및 룰렛 화면으로 이동하는 동작을 제공한다.
- **오류 상태:** 목록 조회에 실패하면 빈 상태로 오인되지 않도록 오류와 재시도 동작을 표시한다. 삭제 및 이미지 다운로드가 실패하면 그 사실을 알리고, 성공한 것처럼 화면이나 데이터를 갱신하지 않는다.

## 4. 데이터 및 범위
- 메인 화면이 표시하는 빌드는 챔피언, 주·보조 룬 경로와 선택 룬, 룬 파편, 선택적인 스킬 마스터리 순서와 아이템 구매 순서, 라인 식별자, 저장 시각을 포함한다. 스킬·아이템 추천 데이터가 아직 없으면 저장하거나 표시할 필요가 없다.
- 저장된 빌드는 PostgreSQL에 보관하며 화면을 다시 열어도 조회할 수 있어야 한다. 챔피언·룬·아이템 표시에 필요한 이미지와 이름은 앱의 공통 게임 데이터에서 가져온다. 라인 식별자는 라인 아이콘을 선택하거나 지정할 수 있을 때 저장하고, 화면에는 라인 아이콘만 표시한다.
- 목록 및 선택 상세 패널은 동일한 저장 데이터를 사용한다. 선택한 빌드를 삭제한 경우 해당 항목만 제거하고, 남은 항목이 있으면 가장 최근 항목을 선택한다.
- 로그인·사용자별 데이터 분리는 현재 범위에 포함하지 않는다.
- 게임 데이터의 갱신 방식은 프로젝트 공통 API 연동 범위를 따른다.

## 5. 완료 기준
- 헤더에 앱 이름과 다크 모드 전환이 표시되고, 전환 시 테마가 바뀐다.
- 저장된 빌드가 최신순 목록에 표시되며, 초기 진입 시 최신 빌드와 그 상세 정보가 선택되어 있다.
- 목록에서 다른 빌드를 선택하면 챔피언, 룬, 선택적으로 저장된 스킬·아이템 데이터, 라인 아이콘이 선택한 데이터와 일치하게 갱신된다. 스킬·아이템 데이터가 없으면 해당 영역이 비어 있다.
- 룰렛 화면에서 생성해 저장한 빌드가 메인 화면 목록과 상세 패널에 표시된다.
- `+` 버튼을 통해 룰렛 화면으로 이동할 수 있다.
- 추천 스킬 마스터리 영역 오른쪽 위의 작은 이미지 버튼을 누르면 현재 선택한 빌드의 챔피언과 룬 구성을 식별할 수 있는 PNG 파일이 다운로드된다.
- 삭제 확인에서 취소하면 데이터가 유지되고, 삭제를 확정하면 해당 빌드만 목록에서 사라지며 올바른 다음 빌드가 선택된다.
- 빈 목록, 목록 조회 실패, 삭제 실패가 서로 다른 상태로 사용자에게 표시된다.

# 룰렛 화면 PRD

## 1. 목적
챔피언과 룬을 무작위로 결정하고, 선택이 끝난 항목을 최종 결과 영역에 반영해 사용자가 진행 상황과 완성된 빌드를 한 화면에서 확인할 수 있도록 한다. 완성한 빌드는 저장해 메인 화면에서 조회·관리한다.

## 2. 사용자 흐름
1. 사용자가 화면에 진입해 챔피언 룰렛과 비어 있는 룬 선택 영역을 확인한다.
2. 사용자가 챔피언 영역의 `Start!` 버튼을 누르면 가로 룰렛이 동작하고, 중앙 표시 위치에 정지한 챔피언이 선택된다.
3. 사용자가 주 룬 경로와 룬, 보조 룬 경로와 룬, 룬 파편을 각각 선택한다. 선택할 때마다 오른쪽 최종 결과 영역이 갱신된다.
4. 사용자는 최종 결과를 확인하고, 모든 필수 선택이 끝나면 하단의 `완성!` 버튼을 눌러 빌드를 저장한다.
5. 저장에 성공하면 메인 화면으로 이동하고, 저장한 빌드를 목록에서 확인한다.

## 3. 기능 요구사항
- **상단 공통 헤더:** 왼쪽에 다크 모드 전환 버튼, 가운데에 앱 로고와 `All Random Challenge` 앱 이름을 표시한다. 테마 전환 시 헤더와 룰렛 영역 전체에 적용한다.
- **챔피언 룰렛 영역:** 헤더 아래 가로형 룰렛을 배치하고, 중앙의 고정 표시(위·아래 화살표)로 현재 선택될 챔피언을 가리킨다. 룰렛 항목은 챔피언 초상화로 표시하며 중앙 항목은 주변 항목보다 크게 강조한다.
  - `Start!` 버튼을 누르면 사용 가능한 챔피언 중 한 명을 무작위로 선택하는 애니메이션을 실행한다.
  - 애니메이션 종료 후 선택된 챔피언을 룰렛 중앙과 오른쪽 최종 결과 영역에 표시한다.
  - 애니메이션 진행 중에는 `Start!` 버튼을 비활성화해 중복 실행을 막는다. 선택 완료 후 재실행할 수 있으며, 새 챔피언으로 교체하면 최종 결과 영역의 챔피언도 갱신한다.
- **룬 선택 영역:** 챔피언 룰렛 아래의 좌측·중앙 영역을 사용해 룬 경로와 세부 룬을 선택한다. 각 룬은 아이콘으로 표시하고 선택 상태를 시각적으로 구분한다.
  - 룬 또는 룬 경로를 선택하면 선택된 아이콘을 주변 아이콘보다 약간 크게 표시하고, 선택되지 않은 선택지는 약간 어둡게 표시한다. 선택 상태는 크기와 밝기만으로 구분하지 않고 보조적인 시각 표시도 제공한다.
  - 선택된 룬 아이콘은 오른쪽 최종 결과 영역의 대응하는 빈 슬롯에 같은 이미지로 즉시 반영한다. 선택 전 슬롯은 빈 상태를 유지하고, 선택을 변경하면 대응 슬롯의 이미지도 교체한다.
  - 주 룬 경로를 선택하면 해당 경로의 핵심 룬 1개와 일반 룬 3개를 선택할 수 있게 한다. 핵심 룬 선택지는 해당 경로의 핵심 룬으로 제한한다.
  - 보조 룬 경로를 선택하면 해당 경로의 룬 중 서로 다른 슬롯에서 2개를 선택할 수 있게 한다. 주 룬 경로와 같은 경로는 보조 경로로 선택할 수 없다.
  - 룬 파편은 제공되는 각 행에서 1개씩 선택한다.
  - 아직 선택할 수 없는 룬은 비활성화하거나 선택 불가 상태를 명확히 표시한다. 경로를 변경하면 이전 경로에 종속된 룬 선택을 초기화하고 최종 결과 영역도 즉시 갱신한다.
- **오른쪽 최종 결과 영역:** 챔피언, 주 룬 경로와 선택 룬, 보조 룬 경로와 선택 룬, 룬 파편을 와이어프레임처럼 구획해 보여준다. 선택이 완료되지 않은 항목은 빈 슬롯 또는 미완료 표시로 남겨 완료 항목과 구분한다. 룬 선택 영역에서 선택된 각 룬의 아이콘 이미지를 대응하는 슬롯에 즉시 표시하고, 선택 변경 시에도 두 영역의 표시를 동기화한다. 선택 가능한 내용과 최종 결과가 서로 일치해야 한다.
- **하단 컨트롤:** 화면 하단 왼쪽에는 와이어프레임에 표시된 `아무 룬` 컨트롤을 배치한다. 이 컨트롤의 선택/토글 동작과 결과에 미치는 영향은 와이어프레임에서 정의되지 않았으므로 별도 동작을 임의로 부여하지 않는다. 오른쪽에는 `완성!` 버튼을 배치한다.
  - 챔피언, 주 룬 경로와 필수 룬, 보조 룬 경로와 룬 2개, 룬 파편 각 슬롯이 모두 선택되기 전에는 `완성!` 버튼을 비활성화한다.
  - 모든 선택이 완료된 뒤 버튼을 활성화한다. 누르면 현재 표시된 빌드 전체를 저장하고, 성공 후 메인 화면으로 이동한다.
  - 저장 요청 중에는 중복 제출을 막는다. 저장 실패 시 화면의 선택 내용을 유지하고 오류 및 재시도 방법을 안내한다.
- **로딩 및 오류 상태:** 챔피언·룬 데이터 로딩 중에는 진행 상태를 표시하고, 데이터 로드 또는 룰렛 실행 실패 시 재시도할 수 있게 한다. 실패를 빈 데이터나 성공 결과로 표시하지 않는다.
- 챔피언·룬 및 아이콘 데이터는 공통 게임 데이터 API에서 가져온다. 데이터 버전 및 갱신 방식은 프로젝트 공통 API 연동 범위를 따른다.

## 4. 데이터
- 저장되는 빌드는 챔피언 1명, 주 룬 경로, 해당 경로의 핵심 룬 1개와 일반 룬 3개, 보조 룬 경로와 서로 다른 슬롯의 룬 2개, 룬 파편 각 슬롯 1개로 구성한다.
- 저장 데이터는 각 항목의 안정적인 식별자와 저장 시각을 포함한다. 표시 이름과 아이콘은 공통 게임 데이터에서 조회한다.
- `아무 룬` 컨트롤이 결과에 영향을 주는 동작으로 정의될 경우 해당 설정도 저장되어야 한다. 현재 요구사항에서는 이 컨트롤의 의미와 동작이 미확정이다.
- 저장된 빌드의 목록 조회·삭제·이미지 다운로드는 메인 화면 PRD를 따른다.

## 5. 완료 기준
- 헤더, 가로형 챔피언 룰렛, 주·보조 룬 및 룬 파편 선택 영역, 오른쪽 최종 결과 영역, 하단 컨트롤이 와이어프레임의 배치에 맞게 표시된다.
- `Start!` 실행 시 사용 가능한 챔피언 한 명이 무작위로 선택되고, 진행 중 중복 실행이 불가능하다.
- 룬 경로와 슬롯의 선택 규칙이 지켜지며, 선택 또는 경로 변경이 최종 결과 영역에 즉시 정확히 반영된다.
- 선택한 룬은 룬 선택 영역에서 약간 크게 강조되고 선택하지 않은 항목은 약간 어둡게 표시되며, 선택한 아이콘 이미지가 오른쪽 최종 결과의 해당 빈 슬롯에 즉시 나타난다.
- 미완료 슬롯과 완료 슬롯을 쉽게 구분할 수 있고, 필수 선택을 모두 마치기 전에는 `완성!` 버튼을 실행할 수 없다.
- 완성된 빌드를 저장하면 메인 화면에서 동일한 챔피언·룬 구성으로 조회된다.
- 데이터 로드, 룰렛 실행, 저장 오류가 정상 결과나 저장 성공으로 오인되지 않으며 재시도할 수 있다.
